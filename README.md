# INFO_6150_Group_Assignment
Repository created for INFO 6150 Group Assignment.

## Project Structure

```
.
├── css/
│   ├── formstyle.css
│   ├── login.css
│   └── style.css
├── images/
├── js/
│   └── login.js
├── README.md
├── index.html
└── landingPage.html
```

## Files and Directories

- `css/`: Contains all CSS files for styling
  - `formstyle.css`: Styles specific to forms
  - `login.css`: Styles for the login page
  - `style.css`: General styles for the project
- `images/`: Directory for storing image assets
- `js/`: Contains JavaScript files
  - `login.js`: Handles login functionality
- `index.html`: Main entry point of the website
- `landingPage.html`: Landing page after successful login

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser to view the main page
3. Navigate through the site to explore its functionality

## Development

To make changes to the project:

1. Edit the HTML files (`index.html` and `landingPage.html`) for structure
2. Modify CSS files in the `css/` directory for styling
3. Update `login.js` for any changes to login functionality
